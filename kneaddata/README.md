## Outputs from samples that were re-preprocessed with KneadData

Human read removal applied before community composition analysis.

**Tool:** KneadData v0.12.4  
**Script:** `/scripts/kneaddata/01_kneaddata.sh`  
**Reference:** hg39 T2T (`/dbs/human_genome/hg_39`)  
**Trimming:** `SLIDINGWINDOW:4:20 MINLEN:50 LEADING:3 TRAILING:3`  
**Decontamination:** strict paired mode (deafult,removes pair if either read maps to human)  
**Samples:** 86 (33 excluded — see `../excluded_samples.txt`)

#### humann3_mpa

**Script:** `scripts/kneaddata/06_bracken_to_mpa.py`  
**Input:** `../../community_composition/bracken/{sample}_bracken.report`  
**Samples:** 86   
86 files: `{sample}.mpa` — MetaPhlAn3-format taxonomic profiles   
Format is tab-separated, 3 columns: 
```
clade_name          NCBI_tax_id   relative_abundance
k__Bacteria         1             85.3
k__Bacteria|p__...  1|2           72.1
...
```

- Emits only the 7 standard NCBI ranks: D→`k__`, P→`p__`, C→`c__`, O→`o__`, F→`f__`, G→`g__`, S→`s__`. Intermediate ranks are skipped.
- Passed to HUMANn3 via `--taxonomic-profile` to skip internal MetaPhlAn and use Bracken-derived taxonomy.
